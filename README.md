# DeepWork.ai — Daily Task Planner

## About the Project

DeepWork.ai is a simple web application designed to help users organize their daily tasks, manage their time, and track their progress.

The application allows users to create tasks, set start and end times, choose priorities, and mark tasks as completed. Its goal is to make daily planning easier and help users focus on important activities.

## Problem and Target Audience

Many people struggle to manage their time, remember important tasks, and organize their daily activities.

DeepWork.ai is designed for students, school pupils, employees, and anyone who wants to improve their time management skills.

## Main Features

- Add tasks with a name, start time, and end time.
- Set task priorities: High, Medium, or Low.
- Mark tasks as completed or incomplete.
- Delete tasks.
- Automatically sort tasks by start time.
- Prevent overlapping time slots between unfinished tasks.
- Display task statistics and daily progress.
- Save tasks in the browser using localStorage.
- View a daily schedule of unfinished tasks.
- Use a responsive interface on desktop and mobile devices.

## Technologies Used

- **HTML** — application structure.
- **CSS** — layout, styling, and responsive design.
- **JavaScript** — task management and application logic.
- **localStorage** — saving tasks in the browser.

The project does not require a backend, external API, or AI integration.

## How to Use

1. Open the application in your web browser.
2. Enter a task name.
3. Select the start and end times.
4. Choose a priority.
5. Click **Add task**.
6. Mark a task as completed when you finish it.
7. Check your daily progress in the statistics section.

The application checks that the end time is later than the start time and prevents unfinished tasks from overlapping.

## Future Improvements

Possible future features include:

Advanced features such as reminders, user accounts, and cross-device synchronization are planned for future versions.
